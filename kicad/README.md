# KiCad workspace — BiBa

Здесь живут все KiCad-проекты (схемы и платы) проекта BiBa.

## Структура

```
kicad/
├── README.md                  ← этот файл
├── common/                    ← общие библиотеки (не дублировать по вариантам)
│   ├── symbols/               ← .kicad_sym (общие символы)
│   ├── footprints/            ← .pretty / .kicad_mod (общие футпринты)
│   └── 3dmodels/              ← .step / .wrl
└── variants/                  ← варианты схем
    └── brushed-bts7960/       ← вариант №1: коллекторные моторы + BTS7960
```

## Как устроен вариант

Каждый вариант = отдельный KiCad-проект в `variants/<name>/`:

- `<name>.kicad_pro` — проект
- `<name>.kicad_sch` — схема
- `<name>.kicad_pcb` — плата (если есть)
- `README.md` — план варианта: таргет, распиновка, BOM, статус

Источник истины по пинам — `firmware/targets/*/target.h` и `target.md`.
Схема обязана им соответствовать.

## Соглашения

- Распиновка в схеме = распиновка в `target.h`.
- Общие библиотеки кладём только в `common/`.
- Новый вариант: копируем структуру существующего и пишем `README.md` с планом.
- Документация по вариантам — на русском.

## Импорт из EasyEDA

Исходники EasyEDA лежат в `variants/<name>/easyeda/`, конвертеры — в `scripts/`:

| Скрипт | Что делает |
|--------|------------|
| `easyeda_netlist.py` | разбирает исходник в `netlist.json` / `components.tsv` |
| `easyeda_sch2kicad.py` | схема EasyEDA → `.kicad_sch` (графика символов 1:1) |
| `gen_pcb.py` | плата EasyEDA → `.kicad_pcb` + `common/footprints/biba.pretty/` |

Плату импортирует штатный конвертер KiCad (`kicad-cli pcb import`), `gen_pcb.py`
поверх него приводит результат к виду репозитория: имена слоёв, библиотека
футпринтов, правила DRC из исходника, перезаливка полигонов. Ему нужен Python
из состава KiCad — ищется сам, при нестандартной установке задайте `KICAD_HOME`.

Имена футпринтов в схеме и на плате должны совпадать, поэтому оба генератора
берут их из общей функции `easyeda_netlist.footprint_name()`.

`gen_schematic.py` — ранний генератор схемы «на глобальных метках», оставлен
для истории; актуальный — `easyeda_sch2kicad.py`.
