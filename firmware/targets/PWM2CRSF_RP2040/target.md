# Таргет: PWM2CRSF_RP2040 — мост HotRC (6×PWM) → CRSF

Это **не контроллер бибы**, а отдельная Raspberry Pi Pico (RP2040). Она
читает 6 PWM-каналов с приёмника HotRC и выдаёт CRSF на UART0. Биба не
отличает её от ELRS-приёмника, поэтому управление переключается заменой
разъёма: ELRS ↔ мост HotRC. Прошивку бибы менять не нужно.

```
 HotRC пульт ))) HotRC приёмник ──6×PWM──► Pico (pwm2crsf) ──CRSF 420k──► BiBa (GP1)
 RadioMaster ))) ELRS приёмник ─────────────────────────────CRSF 420k──► BiBa (GP1)
```

- Env: `pwm2crsf_rp2040`
- Код: [`src/pwm2crsf/`](../../src/pwm2crsf) (`pwm2crsf.c` — логика,
  `pwm2crsf_main.cpp` — пины, прерывания, UART)
- Тесты: `test/test_pwm2crsf`, `test/test_crsf`

## Сборка и прошивка

```bash
cd firmware
pio run -e pwm2crsf_rp2040
# зажать BOOTSEL, подключить USB:
pio run -e pwm2crsf_rp2040 -t upload
```

Можно и без `pio`: скопировать `.pio/build/pwm2crsf_rp2040/firmware.uf2`
на диск `RPI-RP2`.

## Распиновка

| Pico  | Функция            | Куда                                     |
| ----- | ------------------ | ---------------------------------------- |
| GP0   | UART0 TX (CRSF)    | BiBa **GP1** (CRSF RX), туда же, куда шёл TX ELRS |
| GP1   | UART0 RX           | BiBa GP0 (CRSF TX). Можно не подключать: пинги бибы читаются и игнорируются |
| GP2   | PWM вход 1         | HotRC CH1 (сигнал)                       |
| GP3   | PWM вход 2         | HotRC CH2                                |
| GP4   | PWM вход 3         | HotRC CH3                                |
| GP5   | PWM вход 4         | HotRC CH4                                |
| GP6   | PWM вход 5         | HotRC CH5                                |
| GP7   | PWM вход 6         | HotRC CH6                                |
| VSYS  | питание 5 В        | +5 В с CRSF-разъёма бибы; от этой же линии питается приёмник (средний пин любого канала) |
| GND   | земля              | общая: биба, Pico, приёмник              |
| GP25  | LED на плате       | горит — связь есть; мигает 2 Гц — failsafe |

Разъём к бибе такой же, как у ELRS: 5 В, GND, TX, RX.

### ⚠️ Уровень сигнала

GPIO RP2040 рассчитаны только на 3,3 В. Перед подключением измерьте
мультиметром или осциллографом амплитуду PWM на выходе приёмника,
запитанного от 5 В:

- **≤ 3,3 В** — подключать напрямую, для защиты через резистор 330 Ом;
- **≈ 5 В** — ставить делитель 1 кОм (последовательно) / 2 кОм (на GND)
  на каждый канал.

## Преобразование каналов

- `PWM2CRSF_MIN_US`…`PWM2CRSF_MAX_US` (по умолчанию 1000…2000 мкс)
  переводятся линейно в 172…1811. Биба видит это как −1…+1, 1500 мкс
  даёт ровно 992 (0). Значения за пределами диапазона обрезаются.
- Импульсы вне окна 800…2200 мкс считаются помехой и отбрасываются.
- RC-кадры идут с частотой 100 Гц, LINK_STATISTICS — 5 Гц (LQ=100,
  RSSI −50 дБм: реального измерения у PWM-приёмника нет).

### Маппинг

Что измерено на стенде у HotRC:

| Вход | Что это        | Поведение                                       |
| ---- | -------------- | ----------------------------------------------- |
| PWM1 | руль           | ось 1000…2000, центр 1500                       |
| PWM2 | курок газа     | ось 1000…2000, центр 1500                       |
| PWM3 | кнопка         | с фиксацией: каждое нажатие 1000 ↔ 2000         |
| PWM4 | кнопка         | с фиксацией                                     |
| PWM5 | кнопка         | без фиксации: 2000 только пока держишь          |
| PWM6 | кнопка         | импульсов не было (`in6=0!`) — проверить провод |

Раскладка по каналам, которые реально читает биба (`mode_standalone.c`,
`BIBA_CH_*` в `biba_config.h`), задана в [`target_config.h`](target_config.h):

| CRSF | Источник                   | Что это для бибы                          |
| ---- | -------------------------- | ----------------------------------------- |
| CH1  | const 992                  | не используется                           |
| CH2  | **PWM2** курок             | газ                                       |
| CH3  | const 992                  | не используется                           |
| CH4  | **PWM1** руль              | руль                                      |
| CH5  | **PWM3** + блокировка ARM  | ARM: > 0.3 — взведена                     |
| CH6  | **PWM4** счётчик 1→2→3→1   | скорость 1/3 · 2/3 · полная               |
| CH7  | const 172                  | blackbox выкл                             |
| CH8  | **PWM6** как есть          | маячок                                    |
| CH9  | const 992                  | трим 0                                    |
| CH10 | **PWM5** переключатель     | MANUAL ↔ удержание курса                  |
| CH11–16 | const 992               | не используются                           |

Что при этом теряется:

- **Blackbox (CH7).** Кнопок всего четыре. Если запись важнее маячка,
  поставьте в карте `5` на место CH7, а на место CH8 — `-1`.
- **Жест трима.** Для него CH1–CH4 должны одновременно стоять в
  максимуме, с HotRC это недостижимо. CH1 и CH3 держатся в нейтрали,
  поэтому случайно жест тоже не сработает.

### Какие входы обязательны

`PWM2CRSF_REQUIRED_MASK`: связь считается живой, только пока идут
импульсы с **руля, курка и ARM** (PWM1–PWM3). Если молчит любой из них,
мост перестаёт слать кадры, и биба уходит в failsafe.

Если молчит вспомогательная кнопка (PWM4–PWM6), связь не рвётся, а её
канал получает безопасное значение: маячок выключен. У кнопок-счётчиков
остаётся последний шаг.

### Блокировка ARM

После включения и после каждого failsafe мост держит CH5 в положении
«разоружена» (в логе `LOCK`), пока хотя бы раз не увидит кнопку ARM
(PWM3) в положении «выкл». Если кнопка на пульте уже была включена,
биба сама не взведётся: кнопку нужно выключить и включить снова.
`PWM2CRSF_ARM_INPUT = -1` отключает блокировку.

### Кнопки-счётчики: скорость и режим езды

У бибы переключатель скорости на три положения и переключатель режима
на два, а на пульте для каждого одна кнопка. Мост считает нажатия и сам
выставляет каналы:

```
скорость (PWM4 → CH6):  1 (172, 1/3) → 2 (992, 2/3) → 3 (1811, полная) → 1 …
режим    (PWM5 → CH10): MANUAL (172) ↔ HOLD (1811, удержание курса)
```

- После включения и после любого failsafe: скорость 1, режим MANUAL.
  Положение кнопки в этот момент нажатием не считается.
- Переходы кнопки фильтруются: гистерезис 1300/1700 мкс, между
  засчитанными нажатиями не меньше 150 мс.
- `*_BUTTON_LATCHING` задаёт тип кнопки:
  - `1` — с фиксацией, засчитывается каждая смена 1000↔2000
    (скорость, PWM4);
  - `0` — без фиксации, засчитывается только нажатие (режим, PWM5).

  Если одно нажатие перескакивает через шаг, поставьте `0`; если на
  один шаг нужно два нажатия — `1`.
- `*_BUTTON_INPUT = -1` отключает счётчик. Тогда вход нужно прописать в
  карте напрямую.

### Мёртвая зона по центру

Газ у бибы в открытом контуре (RPM-регулятор выключен) идёт в
скважность моторов без мёртвой зоны. У ELRS в центре ровно 992, а курок
HotRC в покое прыгает 1500↔1501 и иногда останавливается на 10–40 мкс
от центра. Из-за этого колёса подёргиваются.

Поэтому для руля и курка (`PWM2CRSF_CENTER_DEADBAND_MASK`) всё в
пределах ±`PWM2CRSF_CENTER_DEADBAND_US` (20 мкс) от 1500 уходит бибе
ровно как 992. Остальной ход растягивается, так что до упора
по-прежнему получается ±1. Если колёса всё ещё ползут при отпущенном
курке, увеличьте значение.

### Инверсия

`PWM2CRSF_INPUT_INVERT_MASK`: бит `i` зеркалит вход `i+1` относительно
1500 мкс. Нужна, если руль крутит не туда (бит 0), курок работает
наоборот (бит 1) или кнопка в выключенном состоянии даёт «верх»
(биты 2–5). Если в пульте есть реверс каналов, лучше пользоваться им.

## Отладка по USB

`pio device monitor -b 115200`. Два раза в секунду выводится строка:

```
[pwm2crsf] LINK ARM spd=2 MANUAL tx=1234 rx_from_biba=180 glitch=2 | in1=1500  in2=1500  in3=1998  in4=2000  in5= 999  in6=   0! | ch2=992 ch4=992 ch5=1810 ch6=992 ch8=172 ch10=172
```

| Поле              | Смысл                                                                 |
| ----------------- | --------------------------------------------------------------------- |
| `LINK`/`FAILSAFE` | шлёт ли мост кадры                                                    |
| `ARM`/`disarm`/`LOCK` | что увидит биба на CH5; `LOCK` — ждём выключения кнопки ARM       |
| `spd`, `MANUAL`/`HOLD` | состояние кнопок-счётчиков                                       |
| `tx`              | сколько RC-кадров отправлено бибе (при `LINK` растёт на 50 за строку) |
| `rx_from_biba`    | сколько байт пришло от бибы: её пинги, примерно +15 за строку         |
| `inN=…`           | длительности импульсов; `!` — вход молчит                             |
| `chN=…`           | что уходит бибе (172 = −1, 992 = 0, 1811 = +1)                        |

Для калибровки поверните руль и выжмите курок до упора в обе стороны.
Если крайние значения заметно отличаются от 1000/2000, поправьте
`PWM2CRSF_MIN_US`/`PWM2CRSF_MAX_US`.

### Проверка связи с бибой

1. **Мост → биба.** В логе моста `LINK` и растёт `tx`. В USB-логе бибы
   раз в секунду `fs=0`, `rssi=50 lq=100`, а раз в 5 секунд в строке
   `CRSF diag` растут `frm` и `ch`, `bad` стоит на месте. Если у бибы
   `fs=1` и `ch` не растёт, проверьте провод GP0 моста → GP1 бибы и
   общую землю.
2. **Биба → мост** (необязательно). `rx_from_biba` растёт. Если стоит на
   0, провод GP0 бибы → GP1 моста не подключён; на работу это не влияет.
3. **ARM.** Выключите и включите кнопку ARM: в логе моста `ARM`, у бибы
   `arm=1` и мелодия.

## Failsafe — прочитать обязательно

Мост перестаёт слать RC-кадры, если руль, курок или ARM молчат дольше
`PWM2CRSF_INPUT_TIMEOUT_MS` (100 мс). Через 500 мс биба уходит в свой
штатный failsafe: моторы стоп, мелодия. Так же ведёт себя ELRS при
потере связи. Когда импульсы вернутся, биба останется разоружённой
(блокировка ARM) на первой скорости и в режиме MANUAL.

**Но** многие PWM-приёмники при потере сигнала импульсы не прекращают:
они держат последнее положение или выдают заранее заданные значения
failsafe. Мост такую ситуацию распознать не может. Поэтому:

1. Настройте failsafe на пульте HotRC: **CH3 (кнопка ARM) — выкл**,
   CH2 (газ) — нейтраль.
2. Проверьте на стенде с поднятыми колёсами: взведите бибу и выключите
   пульт. Биба должна разоружиться (в логе бибы `arm=0` или `fs=1`), а в
   логе моста должно появиться `link lost -> failsafe` либо `disarm`.
3. Пока проверка не пройдена, на землю не ставить.
