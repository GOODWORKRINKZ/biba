# Таргет: PWM2CRSF_RP2040 — мост HotRC (6×PWM) → CRSF

Это **не контроллер бибы**, а отдельная Raspberry Pi Pico (RP2040). Она
читает 6 PWM-каналов с приёмника HotRC и выдаёт CRSF на UART0. Биба не
отличает её от ELRS-приёмника, поэтому управление переключается заменой
разъёма: ELRS ↔ мост HotRC. Прошивку бибы менять не нужно.

```
 HotRC пульт ))) HotRC приёмник ──6×PWM──► Pico (pwm2crsf) ──CRSF 420k──► BiBa (GP1)
 RadioMaster ))) ELRS приёмник ─────────────────────────────CRSF 420k──► BiBa (GP1)
```

- Env: `pwm2crsf_rp2040`
- Код: [`src/pwm2crsf/`](../../src/pwm2crsf) (`pwm2crsf.c` — логика,
  `pwm2crsf_main.cpp` — пины, прерывания, UART)
- Тесты: `test/test_pwm2crsf`, `test/test_crsf`

## Сборка и прошивка

```bash
cd firmware
pio run -e pwm2crsf_rp2040
# зажать BOOTSEL, подключить USB:
pio run -e pwm2crsf_rp2040 -t upload
```

Можно и без `pio`: скопировать `.pio/build/pwm2crsf_rp2040/firmware.uf2`
на диск `RPI-RP2`.

## Распиновка

| Pico  | Функция            | Куда                                     |
| ----- | ------------------ | ---------------------------------------- |
| GP0   | UART0 TX (CRSF)    | BiBa **GP1** (CRSF RX), туда же, куда шёл TX ELRS |
| GP1   | UART0 RX           | BiBa GP0 (CRSF TX). Можно не подключать: пинги бибы читаются и игнорируются |
| GP2   | PWM вход 1         | HotRC CH1 (сигнал)                       |
| GP3   | PWM вход 2         | HotRC CH2                                |
| GP4   | PWM вход 3         | HotRC CH3                                |
| GP5   | PWM вход 4         | HotRC CH4                                |
| GP6   | PWM вход 5         | HotRC CH5                                |
| GP7   | PWM вход 6         | HotRC CH6                                |
| VSYS  | питание 5 В        | +5 В с CRSF-разъёма бибы; от этой же линии питается приёмник (средний пин любого канала) |
| GND   | земля              | общая: биба, Pico, приёмник              |
| GP25  | LED на плате       | горит — связь есть; мигает 2 Гц — failsafe |

Разъём к бибе такой же, как у ELRS: 5 В, GND, TX, RX.

### ⚠️ Уровень сигнала

GPIO RP2040 рассчитаны только на 3,3 В. Перед подключением измерьте
мультиметром или осциллографом амплитуду PWM на выходе приёмника,
запитанного от 5 В:

- **≤ 3,3 В** — подключать напрямую, для защиты через резистор 330 Ом;
- **≈ 5 В** — ставить делитель 1 кОм (последовательно) / 2 кОм (на GND)
  на каждый канал.

## Преобразование каналов

- `PWM2CRSF_MIN_US`…`PWM2CRSF_MAX_US` (по умолчанию 1000…2000 мкс)
  переводятся линейно в 172…1811. Биба видит это как −1…+1, 1500 мкс
  даёт ровно 992 (0). Значения за пределами диапазона обрезаются.
- Импульсы вне окна 800…2200 мкс считаются помехой и отбрасываются.
- RC-кадры идут с частотой 100 Гц, LINK_STATISTICS — 5 Гц (LQ=100,
  RSSI −50 дБм: реального измерения у PWM-приёмника нет).

### Маппинг

На пульте HotRC PWM1 и PWM2 — оси (руль и курок газа), PWM3–PWM6 —
кнопки. `PWM2CRSF_CHANNEL_MAP` в [`target_config.h`](target_config.h)
раскладывает их по каналам, которые реально читает биба
(`mode_standalone.c`, `BIBA_CH_*` в `biba_config.h`):

| CRSF | Источник       | Что это для бибы                                   |
| ---- | -------------- | -------------------------------------------------- |
| CH1  | const 992      | не используется                                    |
| CH2  | **PWM2** курок | газ                                                |
| CH3  | const 992      | не используется                                    |
| CH4  | **PWM1** руль  | руль                                               |
| CH5  | **PWM3** кнопка | ARM: > 0.3 — взведена                             |
| CH6  | **PWM4** кнопка | скорость, переключается по кругу (см. ниже)      |
| CH7  | const 172      | blackbox выкл                                      |
| CH8  | **PWM6** кнопка | маячок                                            |
| CH9  | const 992      | трим 0                                             |
| CH10 | **PWM5** кнопка | низ — MANUAL, верх — удержание курса (STABILIZED) |
| CH11–16 | const 992   | не используются                                    |

Что при этом теряется:

- **Blackbox (CH7).** Кнопок всего четыре. Если запись важнее маячка,
  поставьте в карте `5` на место CH7, а на место CH8 — `-1`.
- **Жест трима.** Для него CH1–CH4 должны одновременно стоять в
  максимуме, с HotRC это недостижимо. CH1 и CH3 держатся в нейтрали,
  поэтому случайно жест тоже не сработает.

### Кнопка скорости

На пульте для скорости одна кнопка, а у бибы переключатель на три
положения. Поэтому мост считает нажатия PWM4 и сам выставляет CH6:

```
старт → 1 (172, 1/3 скорости) → нажал → 2 (992, 2/3) → нажал → 3 (1811, полная) → нажал → 1 …
```

- После включения и после любого failsafe мост всегда стартует с первой
  скорости. Состояние кнопки в момент старта нажатием не считается.
- Переходы кнопки фильтруются: гистерезис 1300/1700 мкс, между
  засчитанными нажатиями не меньше 150 мс.
- Текущая скорость видна в USB-логе (`spd=…` и строка
  `speed N/3` при каждой смене).
- `PWM2CRSF_SPEED_BUTTON_LATCHING` зависит от типа кнопки на HotRC:
  - `1` (по умолчанию) — кнопка с фиксацией: каждое нажатие
    перебрасывает канал 1000↔2000, засчитывается каждая смена;
  - `0` — кнопка без фиксации: 2000 только пока держишь, засчитывается
    только нажатие.

  Проверка по логу: если одно нажатие перескакивает через скорость,
  поставьте `0`; если на один шаг нужно два нажатия — `1`.
- `PWM2CRSF_SPEED_BUTTON_INPUT = -1` отключает счётчик, и PWM4 идёт
  на CH6 как есть.

### Инверсия

`PWM2CRSF_INPUT_INVERT_MASK`: бит `i` зеркалит вход `i+1` относительно
1500 мкс. Нужна, если руль крутит не туда (бит 0), курок работает
наоборот (бит 1) или кнопка в отпущенном состоянии даёт «верх»
(биты 2–5). **Отпущенная кнопка ARM (PWM3) обязана давать низ.**
Если в пульте есть реверс каналов, лучше пользоваться им.

### Калибровка

Подключите Pico по USB и откройте монитор порта
(`pio device monitor -b 115200`). Два раза в секунду выводится строка:

```
[pwm2crsf] LINK rc=1234 glitch=0 | in1=1502  in2=1498  in3=1500  in4=1501  in5=1000  in6=1500
```

Знак `!` после значения означает, что с этого входа нет свежих импульсов.
Поверните руль и выжмите курок до упора в обе стороны. Если крайние значения заметно
отличаются от 1000/2000, поправьте `PWM2CRSF_MIN_US`/`PWM2CRSF_MAX_US`
(через `target_config.h` или `-D` в env).

## Failsafe — прочитать обязательно

Мост перестаёт слать RC-кадры, если хотя бы один **задействованный** вход
молчит дольше `PWM2CRSF_INPUT_TIMEOUT_MS` (100 мс). Через 500 мс биба
уходит в свой штатный failsafe: моторы стоп, мелодия. Так же ведёт себя
ELRS при потере связи.

**Но** многие PWM-приёмники при потере сигнала импульсы не прекращают:
они держат последнее положение или выдают заранее заданные значения
failsafe. Мост такую ситуацию распознать не может. Поэтому:

1. Настройте failsafe на пульте HotRC: **CH3 (кнопка ARM) — в нижнее
   положение**, CH2 (газ) — в нейтраль.
2. Проверьте на стенде с поднятыми колёсами: взведите бибу, выключите
   пульт. Биба должна разоружиться (в логе бибы `arm=0` или `fs=1`), а в
   логе моста должно появиться либо `link lost -> failsafe`, либо in3≈1000.
3. Там же проверьте, что при включении пульта с отпущенными кнопками
   in3 ≈ 1000: иначе биба взведётся сразу при подаче питания.
4. Пока проверка не пройдена, на землю не ставить.
