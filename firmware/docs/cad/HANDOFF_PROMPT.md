## Как подключиться к Fusion (важно, без этого ничего не сделать)

В Fusion 360 установлен add-in, поднимающий локальный MCP HTTP-сервер на
`http://127.0.0.1:27182/mcp` ("MCP Server Adapter"). Это НЕ зарегистрированный MCP-инструмент в
Claude Code — к нему нужно обращаться напрямую через HTTP (curl/python), сессия обычных
инструментов его не видит. Порядок:

1. `POST http://127.0.0.1:27182/mcp` (не `localhost`, а именно `127.0.0.1` — с `localhost` сервер
   отдаёт 403 "Invalid Host header") с телом
   `{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"claude-code","version":"1.0"}}}`,
   заголовки `Content-Type: application/json`, `Accept: application/json, text/event-stream`.
   В ответе за HTTP-заголовок `MCP-Session-Id` — сохрани его.
2. `POST` туда же `{"jsonrpc":"2.0","method":"notifications/initialized","params":{}}` с заголовком
   `MCP-Session-Id: <тот самый>`.
3. Дальше вызовы `{"jsonrpc":"2.0","id":N,"method":"tools/call","params":{"name":"<tool>","arguments":{...}}}`
   с тем же `MCP-Session-Id`.

Доступные инструменты (`tools/list`):
- `fusion_mcp_read` — `queryType`: `document` (search/open/recent открытых файлов), `projects`,
  `screenshot` (PNG base64, есть `direction`: iso-top-right/front/... ), `apiDocumentation`
  (поиск по Fusion Python API), `activeCommand`.
- `fusion_mcp_execute` — `featureType: "script"` выполняет Python-скрипт через Fusion API (функция
  `def run(_context): ...`, вывод через `print()`); `featureType: "document"` — open/close/save
  (**документ НЕ сохранён с прошлой сессии, не сохраняй без явной просьбы пользователя**).
- `fusion_mcp_update` — undo/redo.
- `fusion_mcp_electronics_read` — для Fusion Electronics, тут не нужен.

Я писал обёртку на Python (`fusion_mcp.py`) в scratchpad прошлой сессии — она не переживёт смену
сессии, воссоздай аналогичную сама (initialize → notifications/initialized → tools/call с
`json.dumps`, писать результат в файл с `encoding="utf-8"`, т.к. в модели кириллические имена
компонентов ("Крепление Мотора") и Windows-консоль их ломает при прямом print).

**Известный баг сервера:** если ПЕРЕДАЁШЬ кириллицу внутри Python-скрипта на исполнение (например
ищешь компонент по имени "Крепление Мотора" через `==`), сервер иногда мьютит кодировку и сравнение
не срабатывает (см. `docs/cad/BIBA2_EXT_BAT.md`, там есть обходной путь — обращайся к компонентам по
индексу `root.occurrences.item(0)` и `.item(2)`, не по имени).
